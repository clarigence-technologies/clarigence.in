# Clarigence graphic assets

All five SVG files in this folder are original code-authored illustrations, created for Clarigence. Their editable source is `scripts/create-graphics.js`. They contain no external images, fonts, scripts or network dependencies. Combined SVG payload is approximately 16 KB before compression.

The supplied Avimaytech website informed the use of a glossy hero object, floating capability cards, gradient accents, pill buttons and soft service cards. Its images, source code, client logos, text, statistics and customer claims were not copied. Clarigence's hero globe is an original CSS composition in `visuals.css`.

Website, commerce, CRM and cloud previews are used only for portfolio items explicitly marked as concepts. Published project images continue to take precedence. These illustrations do not represent shipped client work or business results.

`assets/images/clarigence-wordmark.png` is a resized 400 × 87 copy of the existing authorized Clarigence logo. The original full-resolution asset and metadata image remain available unchanged.
